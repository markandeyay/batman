# Spikes S3 and S4, plus the Phase 1 echo precheck

Spec: Sections 8.4, 11.2, 14 (Phase 0b, S3 and S4), PHOTON_NOTES sections A and F.
Script: `scripts/spike-inbound.ts`. Parsers under test: `apps/server/src/location/pin.ts`,
`apps/server/src/speech/stt.ts`.

## Questions

- **S3:** What does an inbound iMessage voice note look like on `app.messages` (content type,
  mime type, container, codec, size, duration)? Can `read()` bytes be converted with ffmpeg and
  transcribed by `gpt-4o-mini-transcribe` within the 15 s budget?
- **S4:** What exactly arrives when the human uses Messages "Send My Current Location"
  (contact content with `urls`, a `.loc.vcf` attachment, plain text with a link)? Does
  `parsePin` extract lat/lng?
- **Echo precheck (Phase 1):** Does `space.send("pong")` and `message.react(Emoji.like)` work
  from our shared-pool project to the human's iPhone, and what id comes back?

## How to run

From the repo root, in PowerShell or Git Bash:

```
npx tsx scripts/spike-inbound.ts 20
```

The argument is minutes (default 20); `60s` means 60 seconds. Ctrl+C (SIGINT), Ctrl+Break
(SIGBREAK) or SIGTERM calls `app.stop()`. The script:

- starts Spectrum with the iMessage cloud provider only (`imessage.config({})`);
- logs every inbound message: platform, id, parentId, sender (last 4 digits), `content.type`,
  and a JSON dump of the content with Buffers shown as `<bytes N>`; read receipts get one line;
- voice: saves the bytes to the session scratchpad `spike-s3\` folder (override with
  `SPIKE_S3_DIR`), logs mime type, size, duration, first 12 bytes in hex, container sniff and
  the CAF `desc` codec, then runs `transcribeDetailed` (ffmpeg to 16 kHz mono WAV, then
  `client.audio.transcriptions.create`) and logs the transcript and latencies;
- contact and attachment: logs urls, file names, mime types, the raw vCard (photo trimmed), and
  the `parsePin` result (Apple Maps `ll=` / `q=` / `coordinate=`, vCard `URL` and `GEO`);
- text: if the sender is `HUMAN_IPHONE_E164` and the text is `ping`, replies `pong` with
  `space.send` and reacts with `Emoji.like`, logging the outbound message id and latencies.
  Nothing else is ever sent.

Save the output for the record, for example:

```
npx tsx scripts/spike-inbound.ts 20 2>&1 | tee spike-s3s4.log
```

## Human steps (iPhone, one batch)

Start the script first and wait for the line `listening on app.messages`. Then, in the iMessage
conversation with Batman's line (the pool number assigned to your iPhone):

1. Text `ping`. Expect a `pong` reply and a thumbs up tapback on your `ping`.
2. Record and send a voice note (hold the mic button) saying:
   **"testing one two three pineapple"**.
3. Tap the **+** button (or the conversation header), choose **Location**, then
   **Send My Current Location** (not "Share My Location"). Send it.
4. Share a contact card: **+** then **Contacts** (or a contact's page, **Share Contact**), pick
   any contact, send it.
5. Optional: open Apple Maps, drop a pin, **Share**, then **Messages** to Batman's line.

Then tell Claude it is done; the log has everything needed to fill in the results below.

## Results

### Smoke test (2026-10-10, no human input)

PASS (connectivity only). `npx tsx scripts/spike-inbound.ts 60s` against the real project:
`Spectrum started` with provider `imessage` only, connected in 568 ms (project "Batman",
slug batma-d68n), stream stayed open with keepalive lines, no inbound messages (none were
sent), auto-stop at 60 s ran `app.stop()` cleanly (stream close 2 ms), exit code 0. Nothing was
sent. A 15 s rerun after adding stream-level redaction of SDK log output also passed.

### S3: voice note

PENDING human step 2. Expected per installed `@spectrum-ts/imessage` source: `content.type ===
"voice"`, `mimeType: "audio/x-caf"` (normalised from UTI `com.apple.coreaudio-format`),
`duration` unset (the provider does not set it), `size` = attachment total bytes. Local check:
ffmpeg 8.0.1 converts a libopus CAF to WAV and the stt unit tests pass with a fake client.

### S4: location pin

PENDING human step 3. Expected: a vCard named `*.loc.vcf` that the provider parses into

text. `parsePin({ urls, vcf: raw })` handles that, the `\,` escaped form, GEO lines, and text
links. Record the exact captured vCard here.

## Open questions

1. `imessage.config(...)` in spectrum-ts 12.10.1 does not type check (parameter resolves to
   `never`, and the result is not assignable to `PlatformProviderConfig`). Reproduced with
   TypeScript 7.0.2 and 5.9.3, from both the repo root and apps/server. The spike casts around
   it; the Phase 1 gateway needs the same cast or a fix upstream. `scripts/spike-probe.ts`
   currently fails typecheck for this reason.
2. The OpenAI key in `.env` is rejected with `401 invalid_api_key` (checked 2026-10-10 with a TTS
   call; key shape is a normal `sk-proj-` key with no stray whitespace or quotes). Until a working
   key is added, the voice note step will log `STT FAIL stage=transcribe` and S3 can only record
   the format half. Batman then falls back to the text-only behavior in DECISIONS.md.
3. Whether iOS sends "Send My Current Location" as a `.loc.vcf` vCard, a text link, or a rich
   link on this Photon path is the point of S4.
